macOS screenshot utility

CursorShot

Capture a window, crop, full screen, or annotated image from anywhere, then return to the app where you started and paste the right payload.

Download for macOS View Source
brew install --cask ps-apps/tap/cursorshot

Fast Capture

Use configurable shortcuts for the picker, current Space, or Cmd-Tab target.

Paste Back

CursorShot saves locally, restores your target app, and pastes image data or a useful path.

Automatic Updates

Installed releases check for updates automatically and keep the app current.

macOS note: release builds are Developer ID signed and notarized. On first launch, macOS asks for Screen Recording and Accessibility permissions.
